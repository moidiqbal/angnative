  2. Node hard floor >= 22.12 (CI pins 22.22.3); pnpm pinned 10.34.9.
  3. AOT ONLY: never import @angular/compiler in runtime/test bundles.

     14.8 KB), <= 250 KB gzip typical app, 0 B for @angular/compiler and

  9. Licence MIT; every README carries the trademark notice verbatim.
  10. Every task ends with: pnpm test green, pnpm run build exit 0,
      pnpm run check:toolchain exit 0, then a git commit with a descriptive
      message (+ pnpm-lock.yaml if deps changed).
