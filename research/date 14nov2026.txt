1. ANALYSIS SUMMARY — WHAT THE RESEARCH FOLDER SAYS
--------------------------------------------------------------------------------

PROJECT: NativeAngular (npm scope @nativeangular/*, MIT licence)
Goal: Render Angular components as real native views (NO WebView) on phones,
watches, TV and desktop — from ONE Angular codebase.

Architecture (approved, M0 spike complete):
  • Backend-agnostic core (@nativeangular/core) on Angular's public
    Renderer2/RendererFactory2 SPI — NO @angular/platform-browser, NO zone.js,
    AOT-only, zoneless.
  • Fabric backend (v0.1) — iOS + Android via React Native Fabric + Expo.
  • Rust core backend (v0.2+) — watchOS / tvOS / visionOS / macOS.
  • Wedge (differentiator): capability-aware runtime — platform declares what it
    can do, component declares what it needs, framework resolves best impl with
    graceful degradation. NO per-platform forks.

CURRENT STATE (as of 12 Nov 2026 research log):
  • M0 — Spike & Skeleton: DONE. Angular 22.2.5 bootstrapped in Node with no
    DOM through a custom Renderer2. 75 tests green, CI green, governance files
    (LICENSE, README, THIRD_PARTY_NOTICES, CONTRIBUTING, CODE_OF_CONDUCT).
  • Packages landed: @nativeangular/core (SPI), @nativeangular/platform
    (DOM-less Angular platform), @nativeangular/testing (fake backend).
  • M1 — Fabric backend MVP: PLANNED (10 tasks). Not started on device work.
    Track worktrees exist for Tasks 1, 3, 4, 5, 8, 11.
  • Readiness scorecard: 14 / 100 (M0 complete, everything product-facing is 0/5
    or 1/5 — no CLI, no device run, no native module matrix, no performance data).

KEY CONSTRAINTS (do not break):
  • Angular exactly 22.2.5, TypeScript exactly 6.0.3, Node >= 22.12
    (CI pins 22.22.x), pnpm 10.34.9.
