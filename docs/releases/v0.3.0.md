# AngNative v0.3.0 — Release Notes (2026-11-26)

**Tag:** `v0.3.0` (local annotated tag; not pushed)
**Previous release:** `v0.2.0`
**Commits since previous tag:** 57

This release wraps the verified AngNative product as it stands on
2026-11-26. The headline is a **socket-only MarketPulse**: BTC/USD 30-minute
OHLC and real base-BTC volume are derived only from executed Coinbase Exchange
`matches` messages. No REST market-data path, seeded history or fabricated
volume remains.

## Highlights

- **Socket-only market data:** `wss://ws-feed.exchange.coinbase.com`,
  `channels:["matches"]`, product `BTC-USD`. The exact working subscription is
  `{"type":"subscribe","product_ids":["BTC-USD"],"channels":["matches"]}`.
  Object-form channels were rejected by the endpoint and are not used.
- **Honest startup and failure behavior:** the host cache starts empty
  (`bars=0 state=connecting`). Bars appear only after real matches arrive
  (physical log observed `bars=1 state=live`). On failure the last-good payload
  is kept with `fresh:false`.
- **Real RxJS cadence:** `interval(30000)` drives one bounded refresh at a
  time through host-backed async fetch/timer capabilities. WebSocket match
  pushes remain a separate path. `/marketpulse/quote` is a host cache read,
  not a REST market endpoint.
- **Host/ABI surface:** `na_fetchAsyncStart` / `na_onFetchResult`,
  `na_timerSchedule` / `na_timerCancel` / `na_onTimerTick`, and the
  owner-scoped C ABI drain `angnative_runtime_bridge_take_host_tasks(handle)`
  with `fetch`, `timerSchedule` and `timerCancel` JSON tasks.
- **Native chart:** `na-candlestick` maps to `Custom:na-candlestick`; the
  physical screenshot shows a painted match-derived candle at bounds
  `[168,826][1064,1134]`.
- **Animation scope:** deterministic `SetStyle` samples `0 → 0.5 → 1` only;
  no wall-clock easing claim.
- **Full evidence command/output record:**
  `docs/evidence/ANDROID-MARKETPULSE.md` section 11 and
  `docs/evidence/ANDROID-SUSTAINED-LOAD.md` physical section.

## Known limitations

- **iOS/Mac:** Swift bindings and staticlib wiring are statically checked;
  `swift build`, `swift test`, Simulator and device runs are **not verified**
  because no macOS/Xcode is available here.
- **MarketPulse test suite:** the historical `OK (9 tests)` generic suite
  belongs to the CoinGecko APK and was **not** rerun against the final socket
  APK. The ABI pass above is `ecosystem-core` instrumentation only.
- **No real-time guarantee:** Coinbase delivery and socket availability are
  external dependencies. Failure keeps last-good data with `fresh:false`.
- **Not implemented / deliberately deferred:** SSE, REST market data,
  fabricated history or volume as market data, real-time animation easing,
  QuickJS bytecode loading, ES module loader, web adapter AOT migration, HMR,
  zero-copy JNI, binary mutation protocol, SSR/hydration.
- **Third-party scope:** DOM libraries are native reimplementations/adapters,
  not unchanged compatibility. AG Grid and ECharts are POC-level. Hermes/V8
  are not integrated — Gate F uses the in-repo `ReferenceEngine`. Desktop real
  window/GPU rendering is not verified; GPU-free integration is.
- **Benchmark caveats:** one physical device, unknown qcom renderer, procstat
  CPU is percent of one core, `top` is instantaneous, `gfxinfo` is cumulative
  after a post-settle reset, memory deltas include GC/settle effects, and
  `process_ms` is not first-frame time. Low-frame samples were retained.
- **Release mechanics:** the tag is local only. No push or GitHub release was
  performed in this environment.
