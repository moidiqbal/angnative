## What's in v0.4.0: iOS

AngNative now builds, tests and runs on **iOS**. This is the first release verified on a Mac (Xcode 27.2, iPhone 17 Pro simulator, iOS 26.4).

- **Angular on iOS, end to end.** The AOT counter bundle boots in QuickJS on iOS. Its 13 nodes become real UIKit views (`UILabel`, `UIButton`, `UIView`), and a native click reaches the Angular listener. Signals and `computed` then update the labels (`Count: 0 → Count: -1`, `even → odd`). No WebView.
- **Rust host engine for iOS.** The unified runtime bridge (host-ffi, Taffy layout, QuickJS) builds for `aarch64-apple-ios` and `aarch64-apple-ios-sim`. QuickJS bindings are generated with bindgen against the iOS SDK.
- **UIKit shell.** A Swift 6 package with a main-actor UIKit view factory that applies Rust ops synchronously, plus a demo app.
- **8 XCTests pass in the iOS Simulator.** They cover the host, batches, layout, the UIKit tree, demo button → Rust `SetTextContent` → `UILabel`, and the Angular round trip.
- **One-command workflow on a Mac:**
  ```bash
  ./scripts/build-ios-native.sh simulator --test   # build + XCTest in the Simulator
  ./scripts/run-ios-simulator.sh                   # install + launch the demo, save a screenshot
  ./scripts/build-ios-native.sh device             # arm64 iOS build (unsigned)
  ./scripts/package-ios-release.sh 0.4.0           # rebuild these release assets
  ```

v0.4.0 also includes everything described in `docs/releases/v0.3.0.md` (socket-only MarketPulse and more), which was never published as a GitHub release, plus web/native HMR and the ANB1 binary protocol.

## Assets

| File | What it is |
|---|---|
| `AngNativeDemo-iOS-Simulator.zip` | The demo app for the iOS Simulator on Apple silicon Macs |
| `AngNativeRuntime.xcframework.zip` | The Rust runtime as an XCFramework (iOS device arm64 + Simulator arm64) with `angnative_host_ffi.h` |
| `SHA256SUMS.txt` | Checksums |

Try the demo without building anything:

```bash
unzip AngNativeDemo-iOS-Simulator.zip
xcrun simctl boot "iPhone 17 Pro"        # any iPhone simulator
xcrun simctl install booted AngNativeDemo.app
xcrun simctl launch booted dev.angnative.demo
```

## Not included

- **A physical iPhone run, or an `.ipa`.** The device build compiles, but it has not been signed or run on a phone yet.
- **The Angular bundle as the demo app's screen.** The Simulator app shows the Rust-driven demo; the Angular path is proven by XCTest (`testRuntimeBridgeBootsAngularBundleIntoUIKit`).
- **A real UIKit touch.** Tests invoke the registered button action directly, because SwiftPM tests have no `UIApplication`.
- **Intel Macs.** The Simulator assets are arm64 only.
- **A macOS CI job.** Not set up yet.

Full evidence: `docs/evidence/IOS-SIMULATOR.md` · build guide: `docs/IOS-BUILD.md`.
