# AngNative v0.4.0 — Release Notes (2026-11-28)

**Tag:** `v0.4.0` (annotated; created from the release branch tip that contains
this document and the fresh-checkout evidence)
**Code under test:** `29af2487c1cdcd3a854d33618db8ef6916bc7a4e` — merge of
`feat/quickjs-bytecode-loader` (`2677230`) and pushed `master` (`dea0beb`)
**Previous release:** `v0.3.0` (`9f90940`, local annotated tag at the time of
this release)
**Commits since `v0.3.0`:** 42 to the reconciled merge commit

This is a **reconciliation and release-engineering** release, not a new product
surface. It preserves the pushed master line (HMR, ANB1 binary mutations,
borrowed-buffer JNI, Angular 22.3.0 / Taffy 0.16.0, fresh-checkout CI fixes)
together with the feature line (host-clock easing, QuickJS bytecode v2 loader,
pending-promise hardening, bytecode CI artifact). The socket-only MarketPulse
product remains the flagship verification target.

## Highlights

- **Reconciled history:** `29af248` has both parents; no side's work was
  dropped. RuntimeBridge keeps both `load_bytecode` and `hmr_reload`. The
  feature register now reflects implemented easing, bytecode v2, HMR, ANB1 and
  zero-copy JNI rather than the old "deferred" rows.
- **Fresh-checkout determinism proven locally:** a clean detached worktree with
  no `node_modules`, `target/` or generated AOT/bundle artifacts reproduced the
  full gate sequence. Exact commands, exit codes, outputs, flake history and
  limitations are in `docs/evidence/RELEASE-0.4.0-FRESH-CHECKOUT.md` with 37
  retained logs under `docs/evidence/release-0.4.0-logs/`.
- **Host-clock easing (priority #4):** recognized non-linear easings use
  `na_nowMs()` (Rust `Instant`) and rAF frames with generation-guarded
  cancel/pause/finish; linear/empty easing keeps deterministic samples.
  No 60 FPS, vsync, GPU, JNI/FFI, protocol or platform claim.
- **QuickJS bytecode v2 (priority #5):** versioned `ANGNQJSB2` container with a
  producer fingerprint; legacy `ANGNQJSB1` is rejected with a regenerate
  message, and a still-pending module-eval promise is an error rather than
  false success. Rust/runtime scope only — no C ABI/JNI/Swift wiring,
  startup-speed, signature/authenticity, ES-module-loader or platform-shell
  claim.
- **Implemented from master, with evidence retained:** same-realm HMR, ANB1
  mutations with JSON fallback, and one-call borrowed direct-`ByteBuffer` JNI.
  No speed-superiority claim; device results from earlier commits remain
  historical evidence and were not repeated for this release commit.
- **Web demo still JIT-free and within budget:** `@angular/compiler` and
  `zone.js` contribute 0 B; 112,263 B gzip against a 128,000 B budget.

## Scope limits and not verified

- **No hosted GitHub Actions run.** This evidence is a local replay of the CI
  command sequence on Windows with Node `26.13.1`, pnpm `10.34.9`, and nightly
  Rust toolchains dated 2026-11-11/13. CI pins Node `22.22.x` and
  `nightly-2026-11-14`; runner equality is not claimed.
- **No iOS/Mac verification:** Swift compile, `swift test`, Simulator and device
  runs remain Ammar's scope. Only the static FFI declaration check was rerun.
- **No Android device rerun for this commit:** emulator/OnePlus results in
  `docs/UNSUPPORTED-FEATURES.md` and the evidence docs are retained historical
  results, not fresh `29af248` runs.
- **No product/performance guarantees:** no real-time or 60 FPS guarantee, no
  startup-speed superiority, no cross-engine (Hermes/V8) claim, no GPU,
  vsync, JNI/FFI/protocol expansion for easing, no signature/authenticity for
  bytecode, no ES-module loader, no SSR/hydration, no full-DOM parity.
- **MarketPulse remains socket-only:** Coinbase Exchange
  `wss://ws-feed.exchange.coinbase.com` with `channels:["matches"]` for
  `BTC-USD`; no REST/bootstrap/history/OHLC/volume path. Socket availability is
  external; failure keeps last-good data as `fresh:false`.
- **`master` not updated:** this release branch and tag do not merge into
  `master`. No source change on the main repository checkout was made.
