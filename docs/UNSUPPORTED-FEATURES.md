# Unsupported / Not-Yet-Tested Feature Register

**Date:** 2026-11-21, updated 2026-11-25. Maintained as part of Phase 7 deliverables.
**Rule:** "not yet tested" is never written as "works".

## Native renderer (all shells)

| Feature | Status | Reason / next step |
|---|---|---|
| Third-party DOM libraries (Material, PrimeNG, NG-ZORRO, Taiga, Spartan) | Unsupported on native path (deferred) | Renderer only understands `na-*` → native widgets. Need native ports or adapters. None of these libraries is installed in this repo, so no unchanged-library run was attempted. Decision and rationale: § Deferred feature decisions below. |
| Third-party DOM-free library spot-check (RxJS 7.8.2) | Implemented & verified (tested) | `pnpm bundle:third-party` bundles the unmodified, lockfile-pinned RxJS 7.8.2 into `dist/aot/rxjs-bundle.js`; ignored test `third_party_rxjs_runs_unchanged_in_quickjs` loads it into the embedded QuickJS runtime and asserts `of(1,2,3).pipe(map(x => x*2)).subscribe(...)` yields `[2,4,6]` with `complete` and no error. This proves one third-party, non-Angular, DOM-free package executes unchanged on the native JS path. It is a **spot-check, not general compatibility**: DOM-heavy UI libraries, NgRx, Transloco, AG Grid, etc. were not installed or run, and no third-party app was ingested end-to-end. |
| AG Grid sorting / filtering / editing / pinning | Not implemented | Grid POC is read-only (`showcases/ecosystem-grid`). |
| ECharts zoom / animation / full option schema | Not implemented | Native Canvas charts POC only. |
| Rich text editing (Tiptap/CKEditor) | Native equivalent built | `showcases/ecosystem-richtext` — native Spannable editor; not unchanged Tiptap compatibility; no HTML import/export, no redo. |
| Calendar (FullCalendar) | Native equivalent built | `showcases/ecosystem-calendar` — native Canvas month grid; month view only, no week/day/agenda, no event sync. |
| Microfrontends (Native Federation) | Not yet tested | Requires JS runtime, absent on native shells. |
| Angular bundle execution on native | Implemented (bootstrap level) | Real AOT bundle runs in QuickJS; `angular_bootstrap_runs_in_quickjs` verified component construction + native `CreateNode` batches. See `docs/CODE-REVIEW-2026-11-22.md`. Full feature parity still absent (below). |
| Angular `(click)` listener round trip on native | Implemented & verified on Android (runtime + real tap) | Renderer registers via `na_addEventListener`; `na_onEvent` routes Rust dispatch to Angular callback; acceptance test asserts one listener fired + new native batch. `EcosystemCoreActivity` keeps the bridge alive and walks native ancestors until a listener responds. Real tap verified on `emulator-5554` and physical OnePlus `b6640c8f`: logcat `Angular tap node=17 -> 1 listener(s)` and UI `Count: 0 → Count: 1`. Verified property: one delivery per event (canonical JS thread-local path + legacy FFI fallback). |
| Angular Forms in QuickJS | Implemented & verified (tested) | Reactive forms: `pnpm bundle:forms` + `angular_forms_work_in_quickjs` verify `FormControl`/`FormGroup`/`Validators`. Template-driven: `pnpm compile:aot:forms && pnpm bundle:framework` + `angular_template_driven_forms_round_trip_in_quickjs` verify `FormsModule`/`ngModel` on `<input>`: JS→native property/text mutations and Rust-dispatched native `input` event→model update. `<input>` maps to `na-text-input`; flat `navigator.userAgent` shim added for Angular's DefaultValueAccessor. |
| Angular i18n (`$localize` translations) in QuickJS | Implemented & verified (tested) | `pnpm compile:aot:i18n && pnpm bundle:framework` build `dist/aot/i18n-app-bundle.js` from `<na-text i18n>Hello {{ name }}!</na-text>`; the AOT output contains `$localize`, `ɵɵi18n`, `ɵɵi18nExp` and `ɵɵi18nApply`. `angular_aot_i18n_translated_text_in_native_tree` registers a translation before bundle evaluation and asserts `Assalam-o-Alaikum AngNative!` in the native tree. Root causes fixed: the `$localize` shim used an unbounded replace loop when AOT passes the literal `\uFFFD0\uFFFD` placeholder (now single-pass split/join), and Angular's i18n runtime needs a flat `Node` constants shim. |
| Angular Router in QuickJS | Implemented & verified (tested) | Real AOT router app (`apps/demo-app/src/router/main.router.ts`, `tsconfig.aot.router.json`) bundles and bootstraps; `angular_router_bootstraps_with_outlet` verifies the outlet anchor and initial route (`HOME ROUTE`) are built in the native tree, and subsequent imperative navigation (`navigateByUrl('/about')`) successfully swaps route components and produces native mutations (`ABOUT ROUTE`). Cycle-free `AbortController`/`AbortSignal` and `URL` shims plus renderer parent-lookup fix resolve blocker F7. |
| Angular Animations engine in QuickJS | Implemented & verified (tested, deterministic samples only) | Real `AnimationEngine` + `AnimationRendererFactory` now run over `AngNativeRendererFactory2` via `provideNativeAnimations()`. `pnpm compile:aot:animations && pnpm bundle:framework` builds `dist/aot/animations-app-bundle.js` from an AOT component with `trigger('fade', ...)` and explicit keyframes at offsets `0 / 0.5 / 1`; ignored test `angular_animation_engine_interpolates_native_styles` asserts an intermediate native `SetStyle opacity: 0.5` mutation between start and end, `start,done` trigger callbacks, and a final native `opacity: 1`. Root causes fixed: Angular creates the root renderer with a null host (now a flat synthetic host), the engine requires `node.nodeType === 1` (numeric DOM-compatible `nodeType`, native kind preserved as `nativeNodeType`), `eraseStyles` writes `element.style[...]` (flat style mirror added), the orphan check needs `containsElement(document.body, el)` (native elements are now treated as attached), and `animate('100ms')` alone yields zero keyframes (explicit keyframes used). The native player applies three deterministic samples through flat numeric-id registries — no wall-clock tweening; real-time easing fidelity is **not verified** and is explicitly deferred (§ Deferred feature decisions). The separate no-op `Element.animate()` shim in the QuickJS DOM shim is still tested by `test_web_animations_noop_driver`. |
| Angular HttpClient in QuickJS | Implemented & verified (tested) | Real `@angular/common/http` bundle loads and DI-based `HttpClient.get()` works. `angular_http_platform_loads_in_quickjs` asserts the body from the host fetch handler (`hello-from-native|GET`) and `HttpResponse.status === 200`. Root cause of the former NG0201: `createEnvironmentInjector()` has scope `{'environment'}`, but its plain `Injector.create()` parent had no `root` scope, so `providedIn: 'root'` tokens (`HTTP_FETCH_MAX_RESPONSE_SIZE`, `PendingTasks`, `REQUESTS_CONTRIBUTE_TO_STABILITY`) were unresolvable. Providing `{provide: INJECTOR_SCOPE, useValue: 'root'}` from the same `@angular/core` instance fixes it. |
| Cross-thread runtime bridge dispatch on Android | Host/C ABI, Android emulator, and physical OnePlus Open verified | Root cause fixed: Android release builds use `panic = "abort"`, so the C ABI's `catch_unwind` could not catch `assert_owner_thread()` and a wrong-thread JNI dispatch would abort the app. Every C ABI entry point now checks the immutable owner `ThreadId` with a non-panicking raw read before touching QuickJS; `dispatch_event` returns `DISPATCH_PANIC` (`u32::MAX`), `load_script` returns `2`, `get_host` returns NULL, `destroy` is a no-op. Host tests: `test_thread_affinity` and `test_c_abi_dispatch_from_non_owner_thread_returns_sentinel_without_panicking`. Verified on `emulator-5554` (Android 14, x86_64) by `RuntimeBridgeThreadAffinityTest.kt` via `.\gradlew.bat connectedDebugAndroidTest --no-daemon`: wrong-thread dispatch → `-1`, load_script → `2`, get_host → NULL, owner bridge still usable, wrong-thread destroy did not abort; 2 tests / 0 failures. First run failed because prebuilt `jniLibs` were stale; rebuilt with `scripts/build-android-native.ps1`. Evidence: `docs/evidence/ANDROID-THREAD-AFFINITY-EMULATOR.md`. Also verified on physical OnePlus Open `b6640c8f` (`CPH2551`, Android 16, arm64-v8a) with `$env:ANDROID_SERIAL = 'b6640c8f'`; 2 tests / 0 failures, evidence: `docs/evidence/ANDROID-THREAD-AFFINITY-ONEPLUS.md`. Separately, UI-thread marshalling of Rust→Kotlin ViewFactory callbacks is now implemented and verified on both devices (4 tests / 0 failures); see `docs/EVENT-BRIDGE.md` and `docs/evidence/ANDROID-VIEWFACTORY-MAINTHREAD.md`. |
| Rust→Kotlin ViewFactory callback UI-thread affinity on Android | Implemented & verified (emulator + OnePlus) | Every `JniBridge` native entry point is marshalled to `Looper.getMainLooper()` with one wait per call; timeouts/exceptions propagate as `IllegalStateException`, and `destroyHost()` clears queued posts. `NativeViewSink` records `Looper.myLooper()` inside callbacks. `ViewFactoryMainThreadTest.kt` passes on `emulator-5554` (Android 14, x86_64) and `b6640c8f` (CPH2551, Android 16, arm64-v8a). `buildLayoutRequest` is pure JSON invoked from the wrapped `runLayout` entry point. |
| iOS build / simulator run (including Swift compile and runtime-bridge smoke test) | Not tested — iOS runtime static-only | No macOS/Xcode in this environment. Swift legacy-host + runtime-bridge bindings and unified staticlib wiring pass the static `check-ffi-declarations.py` check, but `swift build`, `swift test`, Simulator and device runs are not verified. iOS is static-only in this repo: no iOS runtime execution, ABI or device claim is made. Mac checklist in `docs/IOS-BUILD.md`. |
| QuickJS bytecode loading | Deferred (not implemented, not verified) | A feasibility spike found `rquickjs` 0.5.1 bytecode dump/module traits behind feature flags, but no runtime bytecode loader exists. The supported path is self-contained IIFE bundles loaded as text. Evidence: `docs/evidence/BYTECODE-FEASIBILITY-SPIKE.md`. |
| Hermes / V8 engine adapters | Not integrated | The Gate F engine proof is the in-repo `ReferenceEngine` over the `JsEngine` abstraction, explicitly not Hermes or V8. No Hermes/V8 adapter, build or runtime claim is made. Evidence: `docs/evidence/RUNTIME-BRIDGE-GATE-F.md`. |
| Desktop real window / GPU rendering | Not verified | `crates/angnative-desktop/tests/gpu_free_bridge_view_tree_integration.rs` covers the GPU-free bridge/view-tree path only. No real window or GPU rendering was run or verified. Evidence: `docs/evidence/DESKTOP-GPU-FREE-INTEGRATION.md`. |
| Physical OnePlus `b6640c8f` ABI re-verification | Not verified (device offline) | Previously retained ABI/tap/thread-affinity results stand as historical evidence only. A re-verification this round was not performed because the physical device is offline; no new physical-device ABI claim is made. |
| Frame pacing / CPU benchmark | Emulator multi-sample + sustained load + physical single-burst captured | `docs/benchmarks/emulator-multisample.json` (3 bursts per app, instantaneous `top` CPU), `docs/benchmarks/sustained/emulator-20261125-143058.json` (10 apps, 5+5 starts, 3 × 30 s, `status=ok`) and `docs/benchmarks/physical/results.json` (grid on `b6640c8f`); physical multi-sample, sustained CPU and warm-start still not verified. Evidence: `docs/evidence/ANDROID-BENCHMARKS-MULTISAMPLE.md` and `docs/evidence/ANDROID-SUSTAINED-LOAD.md`. |
| `na-candlestick` native chart | Implemented & verified (contract + QuickJS + Android factory + painted pixels) | `na-candlestick` maps to `Custom:na-candlestick`, carries a JSON-string `attr:bars`, and is created by `NativeViewFactory`/`CandlestickView`. The Android UI dump on `emulator-5554` shows `content-desc="Custom:na-candlestick"`; `CandlestickViewFactoryTest` parses the shared OHLC string on-device. A 2-pixel sample of the chart region counted green/red candle pixels, so the chart is painted, not just present. No unchanged ECharts compatibility is claimed. Evidence: `docs/evidence/ANDROID-MARKETPULSE.md` section 7. |
| MarketPulse live crypto feed on device | Verified for CoinGecko BTC/USD OHLC | The active endpoint returned 48 real 30-minute OHLC bars on `emulator-5554`; the UI showed `BTC/USD · 48 bars · CoinGecko public OHLC · 30m bars`. It is a delayed public endpoint, not a real-time guarantee, and has no volume column (`v` is explicitly 0). The earlier Yahoo stock feed returned HTTP 429 and is no longer active. |
| MarketPulse async `HttpClient → host network` | Deferred (synchronous prefetch adapter + Kotlin polling) | Kotlin prefetches on a worker thread and registers a synchronous JS fetch handler before bundle boot; refresh and the 30 s scheduler re-fetch in Kotlin and push `__marketPulseApplyQuote(json)` into an RxJS `Subject`. ## Deferred feature decisions (2026-11-23)

Phase 3 of `docs/plans/2026-11-23-non-ios-gap-closure-design.md` records explicit
statuses for the features that remain outside the supported scope. These are
decisions with rationale, not silent removals and not claims of implementation.
No runtime bytecode loader, Hermes/V8 adapter, real-GPU path or device
re-verification was added by this round for the items listed here; each status
is a truthful description of what is and is not verified in this repository.

| Feature | Decision | Why it is deferred | What would lift the deferral |
|---|---|---|---|
| DOM-heavy libraries unchanged (Material, PrimeNG, NG-ZORRO, Taiga, Spartan, AG Grid, ECharts, Tiptap/CKEditor, FullCalendar, GSAP) | **Unsupported on native path** (`Native reimplementation required` in `docs/ECOSYSTEM-COMPATIBILITY.md`) | Native renderer understands only `na-*` primitives mapped to native widgets; there is no DOM/CSS/contenteditable shim. Grid/charts/richtext/calendar concept demos are native reimplementations (ADR 0003), not unchanged-library runs. No such library is installed or executed in an APK. | Real native ports/adapters for each primitive, or a genuine DOM shim plus end-to-end ingestion of an unmodified library app, each with tests. |
| Real-time animation easing fidelity | **Deferred (not verified)** | The verified `angular_animation_engine_interpolates_native_styles` test applies deterministic samples via flat numeric-id registries; there is no wall-clock tween/easing driver, so real-time easing is not backed by any test or artifact. | A native animation scheduler/ticker driving interpolated styles with timing assertions on the native tree. |
| Zero-copy transport | **Deferred** | The wire format is JSON; correctness, thread-affinity and UI-thread marshalling were prioritized and are verified. No zero-copy implementation or benchmark exists. | Binary framing plus a shared-memory/borrowed-buffer transport with conformance and lifetime tests. |
| Binary mutation protocol | **Deferred** | Mutations currently use named string kinds; JSON is debuggable and covered by the FFI declaration check. No binary schema, decoder or test exists. | A versioned binary schema, decoder and round-trip tests replacing named string kinds. |
| Web adapter AOT migration | **Deferred** | `pnpm compile:aot` produces verified real `ngc` output in `dist/aot/*.js`, but the web browser demo still bootstraps with JIT. This is a scoped follow-up, not an implemented migration. | Switch the web demo bootstrap to consume `dist/aot/bundle.js` and verify with a build/test. |
| Hot Module Replacement (< 1 s) | **Unsupported (deferred)** | No HMR pipeline exists in the QuickJS runtime or web adapter; `packages/cli/src/dev.ts` is a placeholder. The G4 target in `docs/REQUIREMENTS.md` is not met and is not claimed. | A module-invalidation/reload pipeline with state preservation and a measured save-to-screen test. |
| SSR / hydration | **Unsupported (out of scope)** | No server-render or hydrate path exists; native shells have no server stage and `docs/REQUIREMENTS.md` explicitly excludes replacing Angular Web/SSR. | A deliberate scope change plus an SSR pipeline and hydration contract tests. |
| QuickJS bytecode loading | **Deferred (not implemented, not verified)** | `rquickjs` 0.5.1 exposes bytecode dump/module-bytecode traits behind features, but there is no runtime bytecode loader in this repo. The supported path remains self-contained IIFE bundles loaded as text; a feasibility spike is the only artifact. | A real loader plus tests proving AOT bytecode loads and executes; until then no bytecode-loading claim. Evidence: `docs/evidence/BYTECODE-FEASIBILITY-SPIKE.md`. |
| Hermes / V8 engine adapters | **Not integrated** | Gate F proves the `JsEngine` abstraction with the in-repo `ReferenceEngine`, explicitly not Hermes/V8. No adapter crate or engine runtime was added. | Isolated adapter crates with their own lifecycle/conformance tests. Evidence: `docs/evidence/RUNTIME-BRIDGE-GATE-F.md`. |
| Desktop real window / GPU rendering | **Not verified** | Only the GPU-free bridge/view-tree integration test is retained. Real window and GPU paths were not exercised. | A real-window/GPU integration run with retained artifacts. Evidence: `docs/evidence/DESKTOP-GPU-FREE-INTEGRATION.md`. |
| Physical OnePlus `b6640c8f` ABI re-verification | **Not verified (device offline)** | Historical device evidence is retained, but no re-verification was run in this round; the device is offline. | Device back online plus a recorded ABI re-verification run. |

These decisions are consistent with the flagship-only Angular-shell scope recorded
in ADR 0003 and do not imply parity with Angular Web, NativeScript or Flutter.
