# AngNative v0.3.0 Release — Design (2026-11-26)

Status: **validated by user** for local release execution. Scope choice:
“Abhi release” — wrap the currently verified product; do not block the release
on locally unverifiable or deliberately deferred work.

## Objective

Cut a local `v0.3.0` annotated tag that represents the verified state after
57 commits since `v0.2.0`. The terminal feature is MarketPulse socket-only
market data with host-backed async JS capabilities and physical-device
evidence. The release must be honest about what is not verified.

## Decisions

- **Version:** `v0.3.0`; tag is local and is not pushed.
- **Package versions:** remain `0.1.0`; the previous release also used a tag
  independent of package manifest versions. Avoid unnecessary churn.
- **Release notes:** new `docs/releases/v0.3.0.md` with highlights, artifact
  hashes, verified gates, physical evidence and known limitations.
- **README:** release badge, latest-release line and verified-status table
  updated to v0.3.0 and current test counts.
- **Artifacts referenced, not regenerated:** final APK
  `EDD184C13205029483389F2B20FA2BCB3EFDB6C5D4BEB3E107C32A17EEB387B7`,
  `source.zip` `548D0991B19703E8F37F10F62C0582FBBBA6D7F488EEF3D84805BF5027AF8164`,
  AOT asset hashes, physical socket/ABI/sustained logs and JSON.
- **No push:** user explicitly chose local release only.

## Included in the release

- Socket-only Coinbase Exchange WebSocket `matches` BTC/USD feed; 30m OHLC
  and integer milli-BTC volume derived only from executed match price/size/time.
  No REST bootstrap/history/OHLC/volume; failure retains last-good data with
  `fresh:false`.
- Host-backed async JS fetch/timer capabilities and owner-scoped C ABI host
  task drain; real RxJS `interval(30000)` with one refresh in flight.
- Verified Angular AOT/runtime path, 251 JS tests, 154 Rust tests with 17
  ignored, ignored runtime-bridge suite 17 passed, FFI declaration check.
- Physical OnePlus `b6640c8f`: socket boot `bars=0 state=connecting → bars=1
  state=live`, painted `Custom:na-candlestick`, post-change ABI instrumentation
  pass, 11-app sustained repeat with 33/33 valid samples.

## Known limitations (must appear in release notes)

- iOS/Mac build, Swift test, Simulator and device run unverified.
- The historical nine-test generic MarketPulse suite was not rerun against
  the final socket APK; the ABI pass is `ecosystem-core` instrumentation.
- No SSE, no REST market path, no fabricated history/volume, no real-time
  guarantee, no real-time easing fidelity.
- QuickJS bytecode loading, ES module loader, web AOT migration, HMR,
  zero-copy JNI, binary mutation protocol and SSR/hydration remain deferred
  or out of scope.
- DOM libraries are native reimplementations, not unchanged compatibility;
  AG Grid/ECharts are POC-level; Hermes/V8 are not integrated; desktop real
  window/GPU is not verified.

## Release steps

1. Commit this validated design document.
2. Add `docs/releases/v0.3.0.md`.
3. Update README badge, latest-release line, verified-status table and
   MarketPulse status.
4. Run `git diff --check` and `python scripts/check-ffi-declarations.py`.
5. Commit release notes + README.
6. Create annotated local tag `v0.3.0` on the release commit.
7. Verify clean tree, tag target and that no push occurred.
