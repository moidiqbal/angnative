3) HACKER NEWS — Show HN

TITLE:
Show HN: AngNative – Angular on native widgets via a Rust host engine, no WebView

BODY:
Hi HN,

AngNative is an MIT-licensed experiment: a custom Angular Renderer2 that turns
template mutations into batches, a Rust host engine that keeps a shadow tree and
computes Taffy 0.15.1 layout, and platform shells (Android JNI, iOS Swift, desktop
winit+wgpu) that render real native widgets. No WebView in native mode.

What's verified in v0.2.0:
- 108 Rust tests + 208 JS tests pass in CI
- Production AOT uses the real Angular compiler-cli ngc; Ivy component definitions
  are verified in dist/aot
- 10 showcase APKs built and installed on a OnePlus Open (Android 16)
- 10,000-row virtualized grid: 170 frames, 1.76% jank, 6ms p50 on real GPU;
  the same grid on the SwiftShader emulator measured 16.13% jank
- WebViews: 0 in every showcase app

What it is NOT:
- NativeScript is more mature and actually runs your compiled Angular app natively
  today. Our native shells currently drive Rust-built demo trees; wiring the
  QuickJS runtime to execute compiled Angular bundles is the next milestone.
- DOM libraries (Angular Material, PrimeNG, etc.) do not run unchanged — our
  showcases are native reimplementations, clearly labelled.
- No head-to-head benchmark against NativeScript/Flutter/React Native was run, so
  we make no performance-superiority claims.

I've been building an Angular-native experiment for a while and just released v0.2.0. The short version: a custom Renderer2 emits mutation batches, a Rust host maintains the shadow tree and computes layout with Taffy, and the Android/iOS/desktop shells render actual platform widgets (TextView, UIButton, etc.) — no WebView.

Verified: 108 Rust + 208 JS tests, production AOT with real Angular ngc, and 10 showcase APKs installed on a OnePlus Open. The 10k-row virtualized grid measured 1.76% jank / 6ms p50 on real hardware (SwiftShader emulator: 16.13%). WebViews: 0 everywhere.

Important honesty: NativeScript is still the better choice if you need to ship Angular natively in production today — it actually runs your Angular code on device. Our native shells currently render Rust-built demo trees; the QuickJS runtime wiring is the next big milestone. DOM libraries like Angular Material are represented by clearly-labelled native reimplementations, not unchanged compatibility.

Repo + full evidence + comparison doc are in the release notes. Questions welcome — especially about the FFI protocol and layout pipeline.

AngNative's Rust crates (host-core mutation tree, host-layout with Taffy 0.15.1,
