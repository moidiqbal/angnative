1) USER KA MISSION (original brief, summary)
--------------------------------------------------------------------------------
"Native Library Compatibility & APK Showcase Program" — comprehensive
compatibility, demonstration aur benchmarking program for popular Angular UI
libraries + ecosystem libraries. Deliverables: separate Android APK demos,
complete source code, automated tests, compatibility reports.

HARD CONSTRAINT: Zero WebView for all native-mode demonstrations. Capacitor,
WebView, iframe, embedded browser engines — sab forbidden.

Execution rules: incrementally kaam karo, pehle repo inspect, pehla end-to-end
POC, shared infrastructure prefer karo, untested ko complete mat bolo, evidence-
backed tracker rakho, agar library unchanged na chale to closest native equivalent
banao aur limitation clearly likho.
